# RetroEngine 编辑器

桌面程序，用来改一个游戏的图块、调色板、地图、实体、音乐、脚本积木和精灵动画，并在里面编译、试听、运行。界面是中文。`game.c` 仍然可以写特殊逻辑。玩法也可以只写在 `scripts.json` 里，像 `games/blocks` 那样。

## 在 Ubuntu 26.04 上安装一次

```sh
sudo apt install python3-pyside6 python3-pyside6.qtmultimedia python3-pil python3-numpy
```

这几项分别是界面、试听、读写 `tiles.png`、音频缓冲。系统没有 PySide6 包时：

```sh
python3 -m pip install --user PySide6 numpy
sudo apt install python3-pil
```

编译和运行游戏还需要引擎那一套工具，和仓库根目录 README 里写的一样：

```sh
sudo apt install build-essential libsdl2-dev gnu-efi mtools dosfstools \
                 qemu-system-x86 ovmf cc65 fceux gcc-arm-none-eabi mgba-sdl
```

缺哪个，编辑器的「检查依赖」会给出对应的 `apt install`。

装到应用程序菜单：

```sh
make editor-install
```

这会把 `~/.local/share/applications/retroengine-editor.desktop` 写好，图标指向仓库里的 `editor/icon.png`。注销一次或重新登录后，在应用程序里找 **RetroEngine 编辑器**。不装菜单也可以：

```sh
python3 editor/retro_editor.py
python3 editor/retro_editor.py games/platformer
```

## 怎么做一关

1. **文件 → 打开**，选 `breakout` 或 `platformer`。或者 **新建游戏**，从这两个例子复制，也可以从空白模板开始（空白模板会带上 breakout 的字体图块，这样 `bg_text` 能显示）。
2. **图块**：左边是当前页的 256 个图块，右边是放大的 8×8。页下拉框切换 CHR 页，「加一页」把 `tiles.png` 加高 128 像素（最多 16 页，2048 像素）。第 0 页的编号仍是 0–255。左键涂当前颜色，右键取色。可以复制、粘贴、水平或垂直翻转。撤销和重做在「编辑」菜单里。预览调色板只影响编辑器里的颜色，不改图块数据。NROM 构建只接受一页。
3. **调色板**：上面 32 格是这个游戏的颜色（4 组背景 + 4 组精灵）。点一格，再点下面的 NES 64 色。写入 `palette.txt`。游戏里背景的颜色 0 永远用第一格，也就是共用背景色。
4. **地图**：上面的下拉框切换关卡。旁边可以新建、复制、改名、删除、上移、下移，还可以给这一关选背景音乐和「图块页」。图块页写入地图开头的 `tileset N`（0 不写，旧地图保持原样）。新建时高度是 30 行，宽度从 32 到 512，按 32 列加。复制会带上格子、调色板、图块页和实体；新建只复制图例。至少留一关。选图块和背景调色板再涂。勾上「实心」后，这种图块在整张图里都挡人。「画的时候统一 16×16 调色板」会把 NES 的一个属性块涂成同一种调色板。编译页打开 ExRAM 之后，这里改成每个 8×8 用自己的调色板，网格是 8 像素，左边 32 列不再标 16×16 冲突。黄线每 32 列画一条，也就是每一屏的起点。比 64 列更宽的图在游戏里按列流进两屏的 nametable，编辑器里仍是一整张明文地图。右键可以吸一个格子。保存后仍是 `maps/<名字>.txt`；`maps/order.txt` 记下顺序。只有同一图块在不同格子用了不同调色板时，才会多写一段 `palmap:`。没改过的关卡文件不会被重写。
5. **实体**（地图页的图层下拉选「实体」）：左边列出 `entities.txt` 里的类型，图标是真实精灵。左键在图上放置，拖动可以移动，右键或 Delete 删除。选中后黄框圈住，下面的数字是坐标和这种类型的属性（比如敌人的 `left` / `right`）。默认吸附 8 像素，取消勾选后按 1 像素。列表下面写着「已放置 n / 上限」。到上限后再放会被拒绝。**编辑类型** 可以改名字、编号、大小、精灵调色板、图块和属性，写回 `entities.txt`。撤销、重做覆盖涂格子和摆实体。
6. **音乐**：左边是 `songs.txt` 里的曲子。选通道（方波 1、方波 2、三角波、噪声、MMC5 方波 1、MMC5 方波 2），改速度、占空比（噪声通道上这一项是模式）、音量。点钢琴键改当前行，时值用 `4`、`8`、`8.` 或 `t12`（12 帧）。「从此循环」从当前行开始循环。「播放」在编辑器里试听，「音效」按钮播放引擎里那 6 个效果。桌面会话里用 Qt 播放；没有声音服务时改用 `paplay` 或 `aplay`（包 `alsa-utils`）。**导入 FamiStudio 文本** 把曲子追加进来；MMC5Square1 / MMC5Square2 进后两路方波，其它扩展芯片会跳过。`music/*.fms.txt` 不在这个列表里，编译时仍会自动接在后面。撤销和重做包括改音符、加行、删行、循环、速度，以及新建、删除、导入曲子。后两路音量为 0 时，试听和 SDL 都不会把它们混进去。
7. **预览** 用和游戏相同的上色看整张地图，包括 16×16 属性块，实体用精灵叠在上面。**运行 PC** 会先编译再打开窗口。
8. **代码** 改 `game.c`。Platformer 用 `level_load` 读当前关的玩家起点、硬币、终点，以及靠近相机的敌人。Breakout 从 `paddle` / `ball` 读开局位置。别的类型要自己在代码里解释。
9. **编译** 里分别编 PC、UEFI、UEFI 镜像、NES、GBA。NES mapper 默认是「MMC5（默认，128KB PRG/CHR，64KB WRAM）」，也可以选「NROM（32KB PRG + 8KB CHR）」。勾选「ExRAM 扩展属性」会把 `exattr 1` 写进 `nes.txt`（默认关；只影响左边 32 列）。改 mapper 会保存 `nes.txt`，并且 `make` 命令带上 `NES_MAPPER=`。日志里的 `rom ...` 行会显示在提示里。MMC5 是 `mapper 5`、PRG/131072、CHR/131072、RAM/768、WRAM/65536。NROM 仍是 PRG/32768、CHR/8192 和 RAM/768；出现 `32KB PRG 放不下` 时，提示说明这是 NROM，并把 mapper 改成 MMC5 就能用更大的 ROM。固定代码窗口或单个 8KB PRG 窗口放不下时也有对应提示。成功后用运行按钮打开。PC 直接运行编出来的程序；NES 用 fceux；GBA 用 mGBA；UEFI 用 QEMU 和 OVMF。
10. **脚本** 是列表，不是自由拖拽的画布。左边选脚本和事件（游戏开始、关卡开始、每帧、按下按键、玩家碰到实体、实体碰到图块、实体碰到实体、计时器、变量条件、进入区域）。中间是积木树。右边是积木面板：设置变量、播放音效或音乐、删除或生成实体、移动、切换动画、跳关、切场景、显示文字、等待、摇镜头、生命减一、过关、游戏结束、如果、重复、随机、调用函数。点「放进选中的如果/重复」可以把积木套进去。下拉框用这个项目里的实体、曲子、关卡、变量和动画。「检查编译」把错误写成中文。保存的是 `scripts.json`。
11. **动画** 左边编元精灵（每块 8×8 的 dx、dy、图块、属性），右边编动画（帧、时长、循环）。中间预览，可以缩放、洋葱皮、水平翻转。超过 64 个精灵或同一扫描线超过 8 个时，预览下面会警告。每种实体可以选一个默认动画。保存的是 `anims.json`。

**文件 → 保存**（或编译前自动保存）把改过的文件写回游戏目录。没改过的 `songs.txt`、地图、脚本和动画不会被重排。

## 只用积木做一个小游戏

打开 `games/blocks`，或者新建一个游戏。空白模板会带上空的 `scripts.json`、`anims.json` 和字体图块。

1. 在 **动画** 里做 `idle` 和 `run`。站立是图块 `0xA0` 加下面的 `0xA1`，迈步把下面换成 `0xA2`。`player` 的默认动画选 `idle`。
2. 在 **地图** 里放一个玩家和一个硬币。
3. 在 **脚本** 里加「每帧」：如果按住右，就把 0 号角色往右移 1 像素并播放 `run`，否则播放 `idle`。
4. 再加「玩家碰到实体 coin」：播放音效 coin，删除实体，显示 `GOT IT`，等待 20 帧，然后过关。
5. 「检查编译」，保存，到 **编译** 页运行 PC 或 NES。

仓库根目录的 README 有同样的步骤，也写了 platformer 里硬币、终点、告示牌和开关是怎么搬进脚本的。游戏过程中显示的字是 ASCII。中文只用在编辑器里。

## 和命令行的关系

编辑器调用仓库根目录的 `make GAME=<名字> pc|uefi|img|nes|gba`。编 NES 时额外带上 `NES_MAPPER=mmc5` 或 `NES_MAPPER=nrom`，和 `nes.txt` 里的选择一致。`make run` 仍然只编译并启动 PC 版。图块、地图、调色板、实体、音乐和 `nes.txt` 的格式就是 `make` 读的那一套，所以不打开编辑器时，原来的流程照旧。没有 `nes.txt` 的游戏按 MMC5 编。
